# matto Pattern Studio

matto 뜨개공방을 위한 코바늘·대바늘 도안 편집기 프로토타입입니다. 별도 설치나 로그인 없이 브라우저에서 바로 사용할 수 있으며, 한 코드베이스에서 PC와 모바일 화면을 자동 전환합니다.

## 주요 기능

- 코바늘·대바늘 기호 팔레트
- 클릭 배치, 선택·드래그 이동, 복제, 회전, 삭제
- 화면 이동 도구, 스페이스바+드래그, 화면 맞춤, 확대·축소
- 격자 크기·맞춤·표시 설정
- 코바늘 기호 개수·반지름·시작 각도를 지정한 원형 자동 배치
- 작품명, 실, 바늘 호수, 게이지, 설명 기록
- 브라우저 자동 저장
- JSON 백업·복원
- SVG 벡터 저장(기호별 그룹 유지, Illustrator 후편집 지원)
- PNG 이미지 저장 및 인쇄/PDF 출력(편집용 격자 제외)
- PC·태블릿·스마트폰 브라우저 지원
- 모바일 하단 도구막대와 기호·설정 시트
- 모바일 한 손가락 기호 조작, 두 손가락 화면 이동·확대/축소
- 상단 메뉴에서 자동·PC·모바일 화면 수동 전환
- PC와 모바일에서 동일한 JSON 도안 파일 사용

## 사용법

1. 왼쪽에서 코바늘 또는 대바늘 기호를 선택합니다.
2. 가운데 격자를 눌러 기호를 배치합니다.
3. `기호 선택` 도구로 전환해 기호를 끌어 이동합니다.
   - 큰 도안은 `✋ 화면 이동` 버튼으로 전환한 뒤 끌어서 이동합니다.
   - PC에서는 스페이스바를 누른 채 드래그해도 됩니다.
   - `맞춤` 버튼 또는 숫자 `0` 키로 도안 전체를 화면에 맞춥니다.
   - `Ctrl/⌘ + 마우스 휠`로 확대·축소할 수 있습니다.
4. 오른쪽에서 도안 정보와 격자 크기를 설정합니다.
5. 용도에 맞춰 파일을 저장합니다.
   - `SVG`: Adobe Illustrator에서 기호별로 편집할 벡터 원본
   - `PNG`: 투명 배경 이미지
   - `PDF`: 인쇄·배포용 문서

모바일에서는 하단의 `기호`, `선택`, `이동`, `정보` 버튼을 사용합니다. 두 손가락으로 도안을 움직이거나 확대·축소할 수 있습니다.

## 로컬 실행

정적 웹앱이므로 `index.html`을 열거나 아래처럼 간단한 서버를 실행하면 됩니다.

```bash
python3 -m http.server 4173
```

그 후 <http://localhost:4173>에 접속합니다.

## 데이터 안내

현재 프로토타입은 작업 내용을 사용 중인 브라우저의 `localStorage`에 저장합니다. 중요한 도안은 반드시 JSON 백업 파일도 내려받아 보관하세요. 서버나 다른 기기와 자동 동기화되지는 않습니다.
